FAQ

Questions builders ask

Can we start with just one part?

Yes. Most teams start with the part that hurts most, on one site. The other modules can be switched on later, with no data moved twice.

Can it run alongside our current ERP?

Yes. You can keep your current software for accounts while StockLedger runs the site side, and export what your accountant needs to Excel. Moving fully across can come later.

Does it work on the phone at site?

Yes. It runs in the phone's browser with nothing to install. Site engineers mark labour and receive goods there, staff check in with a selfie, and drivers mark deliveries with GPS.

Where is our data kept?

On a server you control, over HTTPS, with nightly backups of the database and every uploaded photo and document. It's your data, and you can export it any time.

What does the warranty cover?

For one year from go-live, any bug, meaning something that doesn't work the way it should, is fixed at no cost. New features you ask for are planned and built with you separately.

What is a bug, and what is a feature?

A bug is something already in StockLedger that doesn't work the way it should: a total that comes out wrong, a button that shows an error, a report that leaves out entries, a screen that breaks on the phone. Bugs are fixed cost-free during the warranty.

A feature is something new, or a change to how StockLedger works: a new report, an extra field, another approval step, a different document format, a link to another system. Features are discussed, planned and agreed with you separately.

Who looks after the server?

The server is monitored with AWS CloudWatch and gets periodic maintenance: security updates, backup checks, database and disk health, and HTTPS certificates. Alerts flag problems early, so they are looked at before they grow.

What if you're not available?

StockLedger is built on standard, widely used technology (Java, Spring Boot, React and PostgreSQL) that any experienced developer can pick up. It comes with documentation, deployment scripts and nightly backups, and access to the source code if I can't continue (source-code escrow) can be written into the agreement.

Can you add a feature we need?

Yes. I build and look after StockLedger myself, so a feature you need is a conversation, not a ticket in a queue. It is planned with you, tested and delivered in days.
